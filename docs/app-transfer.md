# アプリ一覧を別PCへ持ち運ぶ

## インストール済みアプリから書き出す

1. 「アプリ選択」→「JSONエクスポート」を開きます。
2. WinGetソースの利用条件を確認して同意し、「このPCのインストール済みを読み取る」を選びます。
3. 対象件数・ID・配布元と、末尾の読み取り結果・警告を確認します。
4. 足りないソフトがある場合は「名前から不足アプリを探す」で候補を確認して追加し、「書き出し確認へ戻る」を選びます。その後「JSONファイルに保存」で保存します。
5. 別PCの本アプリで「アプリ選択」→「JSONインポート」からファイルを開きます。
6. プレビューを確認し、「アプリの選択へ反映」を選びます。現在の選択は置き換わります。不要な項目は一覧で外せます。
7. 実行内容と利用条件を確認してから導入します。読み込みだけではインストールしません。

通常権限の `winget export` で照合し、WinGetコミュニティ配信とMicrosoft Store配信の両方を扱います。ソースへの接続とWinGetの準備が必要です。読み取り自体ではインストール・削除を行いません。書き出すファイルはWinGetの標準JSON形式です。

バージョンを固定せず、同じ製品・エディション・チャンネルのパッケージIDで最新提供版を選びます。通常版とNightlyなど異なるIDは統合しません。インポートすると更新設定はオフに戻り、既存アプリは既定でスキップします。

## 自動照合から漏れたソフトを名前で探す（v0.5.0）

Windowsのアンインストール登録（現在の利用者・PC全体、32bit/64bit）から名前・バージョン・発行元を読み取ります。例えばWindowsに「Google Chrome」があり、WinGetの自動出力へ含まれなかった場合にも、登録名を選んでWinGetコミュニティの一覧から候補を探せます。非表示のシステム部品や子コンポーネントは補完一覧から除きます。Storeアプリの自動出力は引き続き保持しますが、名前での補完検索はコミュニティ一覧が対象です。

1. 左側の登録名を選びます。登録名の検索も空白で区切ったAND検索です。「自動出力の同名項目を隠す」を解除すると、同名項目が自動出力にある登録も確認できます。同名であることは、自動照合の対応関係を確定したという意味ではありません。
2. 右側に登録名を入力した候補が出ます。「分割した語」から `Google` や `Chrome` だけを選んで範囲を広げたり、入力欄を自由に編集できます。名前が完全一致する候補を先に表示します。
3. 検索方法を選べます。
   - **すべての語（AND）**: `chrome google` は、語順に関係なく両方を含む名前・IDに一致します。大文字小文字を区別せず、全角スペースも区切りとして扱います。
   - **いずれかの語（OR）**: `Chrome Firefox` は、どちらかを含む候補を表示します。
   - **正規表現**: `^Google Chrome$` や `Chrome|Chromium` のように絞り込めます。Rustのregex構文を使い、不正・過大な式はエラー表示にして候補を空にします。500文字までです。
4. 「詳細」で提供元・利用条件を読み、通常版・EXE版・Beta・Dev・Canary・エディション・言語を確認して「追加」を選びます。名前が一致しても自動追加しません。「追加を取り消す」や別候補の追加で修正できます。

検索は取得済みのWinGet全件一覧へローカルで適用します。未取得の場合は、ソースへの同意後に一覧を取得します。「WinGet一覧を更新」で再取得できます。grepやシェルのコマンドは実行せず、正規表現もWinGetへそのまま渡しません。通常のアプリ選択画面の名前検索も、空白で区切ったAND検索に対応します。

確認したパッケージIDを元のWinGet JSONへ追加します。同一IDは重複させず、補完の取り消しでも元の自動出力を削除しません。登録名一覧全体はJSONに含めません。自動照合の警告は補完前の記録として残し、利用者による追加と区別します。ポータブルソフト、登録のないソフト、読み取り権限がない項目は検出できない場合があります。

## 対象と制限

- WinGetの自動照合分と、利用者が名前から確認して追加したパッケージが対象です。候補がないソフトや未確認のソフトは含めず、全ソフトの完全な複製は保証しません。
- 設定・個人データ・ログイン情報・ライセンス・購入状態・インストーラー本体は含みません。購入や認証は別途必要です。
- 移行先で利用できない製品や撤回済みパッケージは導入できません。Storeのアカウント・地域などの条件にも従います。
- カタログに名前がない場合はIDを表示します。特にStore製品は、詳細情報と製品ページで製品名・提供元を確認してください。
- 本アプリのドライバー検出結果・Windows標準アプリの削除選択・実行履歴・同意は含みません。WinGetにソフトとして登録された機器管理ツール等は一覧へ現れる場合があります。移行先で必要か確認してください。ドライバーは移行先で改めて検出します。
- Microsoft公式の標準 `winget` / `msstore` ソースだけを許可します。任意ソースの追加や設定変更はしません。
- WinGetが記録した元のインストーラー追加引数（`InitialOverrideArguments` / `InitialCustomSwitches`）は移行せず、出力から除外します。`Scope` は引き継がず標準の導入範囲を使います。これらの方針はプレビューにも表示します。
- `Version` がある外部JSONも読み込めますが、バージョンを固定しない方針を表示します。非空の `Channel` 指定は未対応として拒否します。チャンネルごとのパッケージIDを使ってください。
- ファイルには利用しているソフトの情報が含まれます。指定された場所へ保存し、本アプリから自動送信しません。

## 選択中のアプリだけを書き出す

「選択中のアプリを使う」を選ぶと、選択と依存項目を本アプリの `schema_version: 1` プロファイル形式で保存します。未選択の独自登録や全カタログは含めません。独自登録のURL・ファイル場所・引数・SHA-256も含むため、内容を確認してください。従来のプロファイルも読み込めます。

ローカルのEXE/MSI本体は含みません。別PCにコピーした後、「見つからないインストーラーのファイルを指定」で移行先の場所を選びます。不足したままでは選択へ反映できません。場所を変更しても元の引数・SHA-256は保持し、導入時に指定ハッシュとの一致を確認します。

## 読み込み時の検証

UTF-8（BOMあり・なし）に対応します。32MiBを超えるファイル、不明フィールド、不正ID、重複、任意ソース、スクリプト、依存循環を拒否します。検証やファイル選択をキャンセルした場合は現在のアプリ選択を変更しません。確定時にはドライバー・削除対象の選択と実行同意を解除します。既存の未選択の独自登録は、IDが競合しなければ保持します。

`winget import` を直接実行せず、本アプリの選択・確認・結果管理へ接続します。
