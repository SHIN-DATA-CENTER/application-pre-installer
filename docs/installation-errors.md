# インストールエラーと対処

## ChatGPT: 0x80073D28

確認日: 2026-11-08。利用者から報告されたエラーコードを、OpenAIの公式資料で確認しました。利用者のPCで同じエラーを再現するインストール試験は行っていません。

`ERROR_PACKAGED_SERVICE_REQUIRES_ADMIN_PRIVILEGES` は、サービスを含むMSIX/AppXパッケージの導入に管理者権限が必要であることを示します。ChatGPTのWindows版についても、管理者の承認が必要であると公式に説明されています。[OpenAI公式資料](https://learn.chatgpt.com/docs/enterprise/windows-deployment#troubleshooting)

### 復旧手順

1. 結果画面のChatGPTで「詳細」から配布元情報を確認します。[ChatGPT Windows版の公式ページ](https://learn.chatgpt.com/docs/app/windows)からもインストーラーを取得できます。
2. 公式ページのWindows用インストーラーを取得し、管理者の承認を受けて導入します。標準利用者の場合は管理者へ依頼してください。
3. ChatGPTが対象の利用者で起動できることを確認します。必要なら本アプリで再選択して導入状態を確認します。既存アプリを更新する設定が無効なら、導入済みの項目はスキップします。

本体は通常権限で使用し、ChatGPTの導入に必要な管理者の承認を行ってください。別の管理者アカウントで導入する場合は、利用者単位のアプリが誰に登録されるかも確認してください。

### 本アプリの扱い

- WinGetの終了コードと、出力中の正確なHRESULT・エラー名からこのエラーを判別します。WinGet自身の終了コードで元のエラーが包まれる場合も対応します。
- 結果は「利用者の操作待ち」とし、管理者権限が必要な理由と復旧手順を表示します。手動導入を案内しただけでは成功になりません。依存する処理も完了扱いにしません。
- 結果の「詳細」には結果と対処全文を表示し、配布元情報の取得に失敗しても結果の説明を残します。詳細ログとセッション履歴にも記録します。
- 本体の自動昇格や、WinGetを管理者として自動再実行する処理は追加していません。この修正はエラー判別・表示と手動導入への案内です。

他の原因が残っている場合は、管理者権限を付与した後も別のエラーが発生する可能性があります。その場合は新しいコードと詳細ログで原因を確認してください。
