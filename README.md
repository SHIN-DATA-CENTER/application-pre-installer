# Application Pre-Installer

Windowsをクリーンインストールした後に、必要なアプリとドライバーを選んで導入し、不要なWindows標準アプリを選択削除する、Rust + Slint製の日本語デスクトップアプリです。

Windows 11 x64・オンライン環境が対象です。配布EXEの起動にRustやSlintのインストールは不要です。

## 使い方

1. インターネットに接続し、EXEを通常権限で起動します。
2. OS・マザーボードを確認します。必要な場合は「WinGetを準備・修復」を選びます。
3. WinGetソースの利用条件を確認し、「WinGet一覧を取得・更新」で全件を取得します。プリセットはなく、初期状態は未選択です。前回取得した一覧がある場合はキャッシュを表示します。
4. 必要に応じて「標準アプリの削除」で検出し、削除するアプリを選びます。この画面ではまだ削除しません。
5. 必要に応じてWindows Updateのドライバーを検索・選択します。検索は省略できます。
6. 削除対象・取得元・利用条件を確認し、同意して実行します。削除対象がある場合は、データや設定が失われる可能性についても確認が必要です。

ドライバー導入時は専用ワーカーの管理者権限を要求します。アプリ本体とWinGetは元の利用者で実行し、各インストーラーが必要とする場合にUACが表示されます。

再起動は利用者が実行してください。再起動後は「前回の処理を確認・再開」から、保存された状態を確認できます。成功済みの項目は再実行しません。中断された項目は状態を再確認し、完了を判断できなければ「確認不能」とします。

各項目の「詳細」で配布元と利用条件を確認できます。ホームページが取得できた場合は配布元のページを開けます。それ以外はWinGetのパッケージ定義を参照できます。ページを開いただけでは成功になりません。

ChatGPT等で`0x80073D28`が発生した場合は、サービスを含むパッケージの導入に管理者権限が必要です。本アプリでは「利用者の操作待ち」として理由と復旧手順を表示します。結果の「詳細」または「詳細ログ」を確認し、公式インストーラーを管理者の承認で実行してください。[エラーと対処](docs/installation-errors.md) に手順を記載しています。

一覧は名前・IDで絞り込み、名前のA→Z／Z→A、IDのA→Z／Z→A、選択中を先にする順序で並び替えられます。「すべてのアプリ・選択中・独自登録」の表示切り替えとタグ検索も利用できます。数万件の一覧は表示中の行だけ描画します。

「タグ一覧から選ぶ」で、WinGet索引から取得できたすべてのタグを一覧表示・検索できます。タグを選ぶとWinGetで絞り込みます。日本語や記号を含む元の表記を保持し、キャッシュと再取得に対応します。

現在のコミュニティ一覧には統一カテゴリーがないため、自動分類や人気順・評価順は実装していません。Microsoft Store側ではカテゴリーを取得できる例がありますが、コミュニティのIDとの照合は別途必要です。タグはパッケージごとの任意の検索用語です。対象・制限・調査の根拠は [WinGet一覧とメタデータ](docs/catalog-inventory.md) に記載しています。

## 別PCへアプリ一覧を持ち運ぶ

「アプリ選択」→「JSONエクスポート」→「このPCのインストール済みを読み取る」で、WinGetが識別できたソフトをJSONへ保存できます。通常のWinGet配信とMicrosoft Store配信に対応し、対象と照合できなかったソフトの警告を確認して保存します。

Google Chromeなどが自動照合から漏れた場合は、「名前から不足アプリを探す」でWindowsの登録名から候補を探して追加できます。空白で区切ったAND検索・OR検索・正規表現、登録名を分割した単語の選び直しに対応します。通常版・EXE版・Betaなどを確認し、選んだIDだけをJSONへ含めます。名前の一致だけで自動追加・導入しません。

別PCでは「JSONインポート」で開き、プレビューから選択へ反映します。不要なものを外し、実行内容を確認して導入してください。読み込みだけではインストールせず、既存アプリは既定でスキップします。同じ製品IDの最新提供版が対象で、設定・個人データ・ライセンスはコピーしません。

「選択中のアプリを使う」で選んだものだけを書き出すこともできます。従来のプロファイルも読み込めます。ローカルのインストーラーが見つからない場合は、移行先のファイルを指定できます。[操作と制限](docs/app-transfer.md)

## 対応範囲

- 自動アプリ導入: WinGetで利用できるパッケージ。配布元の終了コードとインストール済み状態を確認します。
- 独自登録: HTTPSの直接ダウンロードURLまたはローカルのEXE/MSI。引数はJSONの文字列配列、SHA-256は任意です。対話型で起動し、終了後の登録状態も確認します。
- 有償ソフト: 認証・ログイン・購入確認は利用者が行います。
- ゲーム: ランチャーは導入可能、ゲーム本体は公式ストア・ランチャーで操作します。
- ドライバー: WMIとWindows Update Agent APIを利用。現在のPCへ適用可能な配信分を取得し、導入直前にも再検証します。
- 標準アプリの削除: 現在の利用者に登録された対応済みWindows標準Storeアプリを検出し、選択したものだけ削除。Store・App Installer・システム部品・削除不可・他アプリの依存先は除外します。全利用者・新規利用者向けのプロビジョニングや、メーカー製デスクトップソフトは変更しません。[対象と制限](docs/windows-app-removal.md)
- BIOS・UEFI・ファームウェア、適合性不明、メーカーサイト独自配布は自動導入の対象外です。ドライバーはWUAのForceQuietで導入し、対話なしで完了できない場合は結果を表示します。
- 組織管理下のWindows Update設定やWinGetのポリシーは変更しません。
- Windows 10、ARM64、Sモード、完全オフラインは初版の対象外です。

一覧は`winget search . --source winget`で取得し、件数上限は付けません。パッケージIDごとに区別し、通常版・Nightly・メジャー版違いを勝手に統合しません。WinGetコミュニティソースが対象であり、Microsoft Storeの全アプリの列挙は含みません。候補が撤回された場合は取得失敗を表示します。

WinGetのソースとパッケージの規約は別に確認します。独自登録・プロファイルを読み込んだだけではインストールしません。自動再起動を許可するWinGetオプションは指定しません。独自EXEは手動操作への引き継ぎとして実行するため、表示された再起動要求では「後で」を選んでください。

## ビルド・開発

必要なもの: Rust 1.92以上、Visual Studio Build ToolsのC++開発環境、Windows SDK。

```powershell
cargo run -- --demo
cargo run
cargo test --locked
cargo clippy --all-targets -- -D warnings
cargo build --release --locked
./scripts/package.ps1 -SkipBuild
```

配布物は `dist/` に生成します。単体EXE、ZIP、SHA-256、変更履歴、依存ライセンス一覧と原文を含みます。`.cargo/config.toml` でCRTを静的リンクし、SlintはGPUドライバーの導入前にも起動できるソフトウェアレンダラーを使用します。

インストールを行わない診断コマンド（一覧の取得ではキャッシュを保存）:

```powershell
cargo run -- --validate-catalog
cargo run -- --scan-apps --accept-source-agreements
cargo run -- --scan-installed-apps --accept-source-agreements
cargo run -- --check-environment
cargo run -- --scan-drivers
cargo run -- --scan-windows-apps
cargo run -- --scan-tags
./scripts/verify-catalog.ps1 -WriteReport
```

`--demo` はPC情報取得・ダウンロード・インストール・アプリ削除を行いません。一覧取得を操作すると、描画確認用の架空データ20,000件を表示します。標準アプリの検出もデモ用の3件を表示します。タグ一覧は架空の25,006件を表示します。画面・プロファイル・履歴はデモ専用の一時領域を使用します。デモで処理した項目は「成功」にはしません。

## データと構成

通常利用時の保存先: `%LOCALAPPDATA%\ApplicationPreInstaller\`

- `profile.json`: 独自登録等。起動時は登録だけを復元し、選択・同意は復元しません。
- `session.json`: 現在の実行履歴。処理前後に同期・置換保存します。
- `sessions/`: セッションごとの履歴を保存します。
- `logs/`: セッションごとのログ。
- `cache/`: ダウンロードとドライバー専用ワーカーの通信ファイル。
- `cache/winget-catalog.json`: WinGetから実行時に取得した全件一覧。起動時に選択は復元しません。
- `cache/winget-tags.json`: 索引から読み取った全タグと索引のバージョン・取得時刻。

外部への独自テレメトリーや独自アカウントはありません。検索・取得時はMicrosoft、WinGetのソース、選択した配布元へ接続します。ログは共有操作を実装していないため、自動送信しません。

構成・拡張方法は [docs/architecture.md](docs/architecture.md)、一覧とソートの調査は [docs/catalog-inventory.md](docs/catalog-inventory.md)、公開前の検証手順は [docs/validation.md](docs/validation.md) を参照してください。

## 公開

GitHub Actionsでビルド・テスト・配布物の生成を行います。`v*` タグではGitHub Releaseの**下書き**を作成します。初版はコード署名を必須にしていません。実機試験結果を記入し、署名・依存ライセンス・配布物を確認してから公開してください。
